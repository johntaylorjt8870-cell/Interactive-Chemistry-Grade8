# إضافة أول وحدة ودرس — Adding the first unit and lesson

> لا تُنفَّذ أي خطوة هنا قبل توفير صور صفحات الكتاب المدرسي وقراءتها.
> راجع `docs/SOURCE_FIDELITY.md` أولاً.

## 1. تقرير القراءة

قبل أي شيفرة، يُحرَّر تقرير يوضّح لكل صفحة: هل النص العربي مقروء؟ النص اللاتيني؟
المعادلات؟ الأرقام؟ الوحدات؟ الجداول؟ الأشكال؟ التجارب؟ الأسئلة؟
وأي عنصر غير واضح يُذكر صراحة ويُطلب توضيحه.

## 2. تسجيل الوحدة والدرس

كل شيء يُعلن في `src/data/curriculum/registry.ts`:

```ts
const CHEMISTRY: SubjectDefinition = {
  ...,
  status: 'source-verified',
  units: [
    {
      id: 'chemistry-u1',
      slug: 'unit-1',                 // المسار: /chemistry/unit-1
      title: '<عنوان الوحدة كما هو مطبوع>',
      order: 1,
      status: 'source-verified',
      source: { pages: [{ page: '10' }], verified: true },
      lessons: [
        {
          id: 'chemistry-u1-l1',
          slug: 'lesson-1',           // المسار: /chemistry/unit-1/lesson-1
          title: '<عنوان الدرس كما هو مطبوع>',
          order: 1,
          status: 'source-verified',
          source: { pages: [{ page: '10' }, { page: '11' }], verified: true },
          steps: [ /* ... */ ],
          studentNotebook: lesson1Notebook, // إلزامي لكل درس source-verified (تبويب «دفتر الطالب»)
          tests: [ /* الاختبار النهائي */ ],
        },
      ],
    },
  ],
}
```

## 3. بناء الخطوات

كل خطوة وحدة عمل واحدة، بترتيب الكتاب:

| النوع | الاستخدام |
| --- | --- |
| `source` | نص الكتاب حرفياً + رقم الصفحة |
| `explanation` | شرح المنصة (يُوسم تلقائياً) |
| `example` | مثال محلول بخطوات التفكير |
| `experiment` | خطوات عملية + قياسات + نتيجة (تفاعل حقيقي) |
| `simulation` | محاكاة مرتبطة بعنصر مسجَّل في `src/simulations/registry.ts` |
| `activity` | نشاط موجّه |
| `question` | سؤال داخل الشرح (بلا تصحيح فوري) |
| `apply` | تطبيق القانون في حالة جديدة |
| `note` / `common-error` | تنبيه / خطأ شائع |
| `summary` | خلاصة |
| `final-test` | اختبار شامل 10–20 سؤالاً جديداً |

## 4. العناصر التفاعلية

تُسجَّل في `src/simulations/registry.ts` وتُحمَّل عند الحاجة فقط:

```ts
defineInteractive({
  id: 'new-chemistry-interactive',
  kind: 'simulation',
  title: '…',
  description: '…',
  load: () => import('./NewChemistryInteractive'),
})
```

كل عنصر تفاعلي يجب أن يملك حالة حقيقية (فعل → ملاحظة/قياس → نتيجة)، وأن يحترم
`prefers-reduced-motion` (يُمرَّر إليه عبر `InteractiveProps.reducedMotion`).

## 5. قبل الدمج

```bash
npm run verify   # أنواع + اختبارات + بناء + تحقّق من مخرجات الإنتاج
```

وتأكد من:

* كل خطوة مصدرية تحمل `source.pages` و`verified: true`.
* لا نص مُلخَّص أو معدَّل داخل `textbook-verbatim`.
* كل إضافة من المنصة داخل `PlatformAddition` أو بوسم `attribution: 'platform'`.
* الاختبار النهائي: 10–20 سؤالاً، بلا نسخ حرفي لأسئلة الكتاب، وبتنويع في الأنماط.
* كل سؤال من الكتاب يحمل `origin: 'textbook'` و`source.page`.
* **دفتر الطالب (`studentNotebook`) مكتمل ومُلحَق بالدرس**: لا يُعدّ أي درس بحالة `source-verified` مكتملاً دون تبويب «دفتر الطالب» المستوفي لمعيار `validateStudentNotebook` في `src/data/sourceFidelity.ts` وجدول المصادر الختامي الموحّد.
* حلول أسئلة الكتاب والاختبار النهائي تُضاف في مساحة المعلم مع رقم الصفحة.

## 6. قواعد تعليمية دائمة لكل درس جديد

### شرح المنصة: عميق وواضح بلا تكرار

يبقى الكتاب مصدر الحقيقة كاملاً وبترتيبه، ويأتي شرح المنصة حوله ولا يحل محله. عند ملاءمة
المفهوم، يشرح المؤلف: ما المفهوم، ولماذا نحتاجه، وكيف يعمل، ومعنى المصطلحات والرموز
والمتغيرات والوحدات والعلاقات، وكيفية اختيار القانون والتعويض والحساب وقراءة النتيجة والتحقق
منها، والأخطاء الشائعة والفروق بين المفاهيم المتشابهة. المطلوب شرح **عميق وواضح وممتع**، لا
نص طويل مكرر أو معلومات تتجاوز مستوى الطالب بلا غرض تعليمي.

### قرار التفاعل قبل التأليف

قبل تثبيت كل مفهوم، يُسأل: هل توضح الحركة أو التجربة البصرية أو المقارنة التفاعلية هذا المفهوم
أفضل من النص وحده؟ إذا كانت الإجابة نعم، يُبنى تفاعل حقيقي وفق التسلسل:

**فعل → ملاحظة أو قياس → استنتاج**

يجب أن تغيّر الأزرار والمنزلقات حالة علمية فعلية، وأن تخدم الحركة هدفاً تعليمياً معلناً، وأن
تعمل بلوحة المفاتيح وعلى الهاتف، وأن تحترم `prefers-reduced-motion`. تُمنع الحركة الزخرفية
والأزرار عديمة الأثر والمحاكاة التي لا تمثل علاقة علمية. كل تفاعل غير وارد في الكتاب يحمل وسم
**إضافة من المنصة**.

### الرسوم التعليمية

تُستخدم رسومات SVG أو Canvas أو مخططات DOM المتحركة عندما تكون البنية أو الحركة أو التسلسل
جزءاً من الفهم، ولا سيما في التجارب والجسيمات والذرات والروابط والتفاعلات. لا يعاد رسم
شكل معقد من الكتاب إن لم يكن مقروءاً بما يكفي لإعادة بنائه بأمانة.

### الرياضيات والترميز العلمي

* كل عملية أو سلسلة حسابية وحدة LTR معزولة، وتُعرض عبر `MathFormula` أو `EquationRow`؛ لا
  تُترك معادلة نصية داخل تدفق RTL.
* الكسور المقصودة رياضياً تُكتب بـ KaTeX مثل `\\frac{1}{2}`، لا بشرطة مائلة نصية.
* الصيغ الكيميائية والأيونات والقيم والوحدات والترميز النووي ورموز العناصر اللاتينية تستخدم
  المكوّنات العلمية المخصصة، ولا تعتمد على اتجاه الصفحة أو المسافات.
* `NuclearNotation` هو الطريق الوحيد للترميز النووي المرئي: العدد الكتلي أعلى اليسار، والذري
  أسفل اليسار، والرمز اللاتيني ملاصق لهما. حتى القيم التسلسلية في الجداول تتحول إلى DOM منظم.

* الشحنات تُكتب في المصدر بصيغتها المرتفعة (`Ca²⁺` · `Cl⁻` · `e⁻`) ويحوّلها المحرّك إلى `<sup>`
  حقيقي؛ لا تُكتب إشارة سائبة على السطر، ولا حالة خاصة لنص أو سؤال بعينه. و`e⁻` و`2e⁻`
  معترف بهما صراحةً كأيون إلكترون.
* الأشكال الثلاثة للشحنة مقبولة ويعالجها المحرّك نفسه: الأصلية (`Ca²⁺` · `NH₄⁺`)، واللاتينية
  (`Ca2+` · `NH4+`)، والقبّعة (`Ca^2+`). والنوع الواحد يبقى متماسكاً: `NH₄⁺` = `<sub>4` مع `<sup>+`،
  و`SO₄²⁻` = `<sub>4` مع `<sup>2−`.
* **كل نصّ محتوى يمرّ عبر المحرّك:** أي حقل قد يحمل شحنة أو صيغة (حجج الحلول، عناصر الترتيب
  والمطابقة، وصف الشكل، نص مرحلة المحاكاة، العدّادات) يُغلَّف بـ `ScientificNotationText` أو
  `ScientificText`؛ عرضه نصاً خاماً يعني بقاء الإشارة على السطر.
* المدى (`18–23`) والعلاقة الكاملة (`2 + 3 = 5`) وحدات واحدة معزولة، لا سلاسل مقاطع قد يعيد
  RTL ترتيبها.
* كل عدّاد يخلط العربية بأرقام (`الخطوة 3 من 27` · `2 من 2` · `18 من 20`) يُغلَّف بـ `<RtlRun />`
  بدل الاعتماد على وراثة الاتجاه من الأب.
* التفاصيل الكاملة والعقود الدائمة: `docs/SCIENTIFIC_RENDERING.md` — قسم «قواعد دائمة على مستوى
  المنصة».

### دفتر الطالب: متطلّب إلزامي دائم لكل درس مكتمل

لا يُعدّ أي درس جديد بحالة `source-verified` مكتملاً ولا يجتاز التحقق الآلي (`validateLesson` / `validateCurriculum`) إلا إذا تضمّن **دفتر طالب كاملاً (`studentNotebook`)** يظهر كآخر تبويب في مخطط الدرس نفسه بعد آخر محطة تعليمية مباشرة، وفق القواعد الدائمة الآتية (مرجع النموذج المعتمد: الدرس السادس `chemistryLesson6Notebook.ts` والدرس السابع `chemistryLesson7Notebook.ts`):

1. **الشمول الدراسي الكامل (مكيَّف تلقائياً مع طبيعة كل درس)**: يضمّ الدفتر كامل مادة الدرس اللازمة للمراجعة والطباعة دون العودة إلى شاشة أخرى: الأهداف والكلمات المفتاحية، جميع التعريفات والمصطلحات، الشرح المنظّم لكل فكرة، القوانين والعلاقات والرموز والواحدات (إن وجدت)، الأمثلة والتطبيقات المحلولة خطوةً بخطوة، الجداول والمقارنات، التجارب أو الأنشطة وملاحظاتها واستنتاجاتها (إن وجدت)، الصور أو الرسوم الثابتة الضرورية للفهم، الإثراء العلمي (إن وجد)، خلاصة «تعلّمتُ»، الأخطاء الشائعة وتصحيحها، و**الحلول الكاملة لجميع أسئلة وأنشطة الدرس و«أختبر نفسي»**، مع بطاقة مراجعة ذاتية (`checklist`).
2. **متن نظيف خالٍ من الضجيج التحريري**: يُضبط `hidePageTagsInBody: true`، وتُترك حقول `section.source` و`definition.source` فارغة، ولا تُدرج أرقام صفحات أو وسوم مصدرية داخل متن الدفتر أو جداوله أو عناوين أشكاله.
3. **الترقيم المتسلسل وجدول المصادر الختامي الموحّد**: يُرقَّم كل بند في متن الدفتر برقم هندي فريد متسلسل (`١ ـ `، `٢ ـ `، …)، ويُختتم الدفتر بجدول مصادر وحيد بعنوان **`جدول مصادر بنود دفتر الطالب`** يطابق جميع البنود واحداً لواحد بالأعمدة الخمسة (`البند` | `النوع` | `التصنيف` | `المصدر` | `الصفحة`)، مع فصل صريح بين المطبوع في الكتاب، وإضافات المنصة التعليمية، وحلول الأسئلة، والرسوم التخطيطية، والإثراء، وأي افتراض معلن أو تدقيق حسابي/مصدري.
4. **أشكال ثابتة وقابلة للطباعة بالكامل**: لا يُخفى أي محتوى أساسي في الدفتر خلف أزرار كشف أو أدوات تفاعلية، وتُمنع الأشكال التفاعلية (`kind: 'interactive'`) داخل الدفتر؛ تُعرض الصور المصدرية أو الرسوم التخطيطية الثابتة كاملةً على الحاسوب والجهاز اللوحي والهاتف وعند الطباعة (`@media print`).
5. **أمانة التحقق البصري**: إذا لم تُعايَن مسوح الصفحات الكاملة مباشرةً يُضبط `notebook.source.verified = false` مع ملاحظة صريحة في `readability.notes`، ولا يُدَّعى التحقق المباشر إلا لما عُوينت أصوله فعلاً.
6. **توافق الدروس السابقة المعتمدة**: تبقى الدفاتر المعتمدة سابقاً مصونةً ضمن استثناء مغلق بالمعرّف في `src/data/sourceFidelity.ts` (الدرسان 3 و4 بنمط الوسم السابق، والدروس 1 و2 و5 بالجدول الختامي المجمّع)، بينما يخضع كل درس من الدرس السادس فصاعداً — وكل درس مستقبلي في أي وحدة — للمعيار الصارم الكامل تلقائياً.

### مساحة المعلم والاختبار

يحصل كل درس على تبويب مستقل لا يخلط محتواه بدروس أخرى. ويحتوي حلول أسئلة وأنشطة الكتاب،
والاختبار الشامل الجديد، وحلوله. الحل الحسابي الكامل يرتب: المعطيات، المطلوب، القانون، شرح
الرموز، التعويض، الحساب، الوحدة، النتيجة، تفسيرها، والتحقق منها. الاختبار 10–20 سؤالاً جديداً
متنوعاً يقيس الفهم، ولا يكشف التصحيح قبل التسليم.

## 7. ترتيب الأولويات

عند المفاضلة بين التعديلات، يكون الترتيب: أمانة المصدر، صحة العلم، صحة RTL/LTR، وضوح الشرح،
جودة التفاعل، جودة مساحة المعلم، تجربة الطالب، ثم التفاصيل البصرية. لا يعاد بناء عنصر يعمل
جيداً لمجرد تغيير مظهره.
