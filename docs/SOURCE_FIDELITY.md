# أمانة المصدر — Source Fidelity

## القاعدة الأساسية

> **الكتاب المدرسي هو المصدر الوحيد للحقيقة.**

لا يُخترع في هذه المنصة: اسم وحدة، اسم درس، تعريف، قانون، رمز، وحدة قياس، قيمة عددية،
شكل، خطوة تجربة، أو سؤال. كل عنصر دراسي يُنقل من الكتاب كما هو، ومرتّباً كما هو.

## التمييز بين المصدرين

| المصدر | الوسم في الواجهة | المكوّن |
| --- | --- | --- |
| نص الكتاب حرفياً | «من الكتاب المدرسي» + رقم الصفحة (ورقم السؤال/النشاط عند توفره) | `TextbookSource` |
| إضافة تعليمية من المنصة (شرح، مثال، محاكاة، سؤال) | «إضافة من المنصة / Platform Addition» | `PlatformAddition` |

لا يجوز أن يظهر محتوى من إعداد المنصة داخل إطار «من الكتاب المدرسي»، ولا العكس.

## ترتيب العمل عند توفير صور الصفحات

1. **القراءة أولاً.** تُقرأ صور الصفحات المزوّدة قبل كتابة أي سطر محتوى.
2. **تقرير الوضوح.** يُسجَّل لكل صفحة: النص العربي، النص اللاتيني، المعادلات، الأرقام،
   الوحدات، الجداول، الأشكال، التجارب، الأسئلة — كل واحد منها:
   `clear` / `partial` / `unreadable` (انظر `SourceReference.readability`).
3. **لا تخمين.** أي عنصر غير واضح يُطلب له توضيح أو يُحفظ كصورة مصدر (`source-image`)
   بدلاً من إعادة رسمه أو تقدير قيمته.
4. **البناء.** تُبنى الوحدة/الدرس من الصفحات، بترتيب الكتاب، دون حذف أو تلخيص أو إعادة صياغة.
   كل خطوة تحمل `attribution` و`source.pages`.
5. **الإضافة.** تُضاف شروح المنصة في خطوات مستقلة موسومة، أو داخل بلوكات
   `attribution: 'platform'`.
6. **التدقيق.** يُشغَّل `npm test` — واختبارات الأمانة تكشف آلياً:
   خطوة تدّعي مادة كتاب بلا مرجع صفحة، بلوك نصي فارغ، درس موصوف بـ `source-verified`
   بمصدر غير مُتحقَّق، اختبار نهائي بلا مرجع، وسؤال من الكتاب بلا رقم صفحة.

## هيكل المراجع في البيانات

```ts
// src/data/curriculum/schema.ts
{
  id: 'step-source',
  kind: 'source',
  title: '<عنوان الخطوة كما في الكتاب>',
  attribution: 'textbook',
  source: {
    pages: [{ page: '42', item: 'نشاط 1', scanId: 'scan-042' }],
    verified: true,
    readability: { arabicText: 'clear', diagrams: 'partial', notes: 'الشكل 3 غير واضح' },
  },
  blocks: [
    { kind: 'textbook-verbatim', text: '<النص كما هو>', source: { page: '42' } },
  ],
}
```

## حالات المحتوى

| الحالة | المعنى | هل تُنشر؟ |
| --- | --- | --- |
| `awaiting-source` | لم تُوفَّر صفحات بعد | لا — تظهر حالة «بانتظار صفحات الكتاب» |
| `in-progress` | قيد الإعداد | لا |
| `source-verified` | قُرئ من الصفحات ودُقّق | نعم |

## واجهات ممنوعة

* عرض درس أو وحدة بلا مرجع مصدر.
* توليد عناوين أو أسئلة «مؤقتة» لتعبئة الواجهة.
* تقدير قيمة عددية أو وحدة مفقودة من صورة غير واضحة.
* إعادة رسم شكل معقّد تخميناً بدل حفظ الصورة الأصلية.
