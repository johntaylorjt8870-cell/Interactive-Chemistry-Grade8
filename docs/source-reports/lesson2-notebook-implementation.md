# تقرير تنفيذ دفتر الطالب — الروابط الكيميائية

الحالة: نسخة للمراجعة، وليست موافقة على النشر. لم تُنفّذ أي عملية Git خلال التنفيذ.

## 1. الملفات

### مشتركة معدّلة
- `src/data/curriculum/schema.ts`: نوع رسم اختياري محدود المفاتيح، ومفتاح أداة اختياري على القسم.
- `src/lessons/StudentNotebookView.tsx`: فرع رسم جديد ونقطة تحميل أداة محاطة بـ Suspense وحدّ احتواء للأخطاء.

### خاصة بالدرس الثاني
- معدّل: `src/data/curriculum/chemistryLesson2Notebook.ts`.
- معدّل: `src/styles/lesson2.css`، بتنسيقات محصورة في معرّف الدرس الثاني؛ قواعد إزالة واجهة التنقل عند طباعة هذا الدفتر فقط.
- جديد: `src/lessons/lesson2NotebookFigures.tsx`.
- جديد: `src/lessons/lesson2NotebookWidgets.tsx`.
- معدّل: `tests/lesson2Notebook.test.tsx` ضمن استثناء تحديث المواصفات القديمة.
- جديد: `tests/lesson2NotebookContent.test.tsx`.
- جديد: `tests/lesson2NotebookWidgets.test.tsx`.
- هذا التقرير ملف توثيق جديد.

لم تُعدّل `LessonFlow.tsx` أو `notebookStaticFigures.tsx`، ولم يُنشأ `notebookInteractive.tsx`. لم تُعدّل محتويات الدروس الأخرى أو اختبارات الدروس الأخرى، ولا `chemistryLesson2Extra.ts` أو بقية محتويات الدرس الثاني.

## 2. المعمارية وسبب ضرورتها

المسار القائم محفوظ: `LessonFlow → StudentNotebookView → NotebookSectionView`.

1. أضيف إلى `NotebookFigure` فرع `lesson2-static` بمفاتيح الرسوم الثمانية المنفّذة فعلاً. ينتهي إلى `NotebookFigureView → Lesson2NotebookFigure`. الأنواع السابقة لا تمثّل هذه الرسوم المركبة؛ لا يكفي ملف رسم محلي وحده ليعرف العارض الحالي كيف يستدعيه. بقيت الفروع القديمة دون تغيير.
2. أضيف إلى `NotebookSection` مفتاح `notebookTool` اختياري بقيم `charge | ionic | lewis | compare`. العارض يستدعي الأداة فقط عند وجوده. لا يوجد حقل أمثلة جديد ولا بطاقات عامة ولا نظام تفاعل عام جديد.
3. الملف الثابت مستورد مباشرة، ولا يستورد الأدوات. الملف التفاعلي وحده مؤجّل التحميل. فشله محتوى داخل حدّ أخطاء، لا يحيط بالنص أو بالرسوم. حدّ الأخطاء لا يزيل أي محتوى علمي أساسي.
4. جميع الأمثلة تستخدم حقول المحتوى الموجودة: نقاط، قوائم مرتبة، جداول، إجراء ورسوم. الحلول كاملة افتراضياً ولا تُغلق بعناصر طي.

الاختيارية وحدها ليست برهان عدم التأثر. البرهان العملي المستخدم: اختبارات الدروس القائمة، اختبارات الدمج، فحص وجود الأدوات والرسوم الجديدة حصراً في الدرس الثاني، ولقطات عرض وطباعة للدروس 1 و3–7. لم يُجرَ قياس فروق حجم الحزمة مع نسخة أساس، ولا مقارنة بكسلية قبل/بعد؛ لذلك لا يوصف الأثر بأنه «صفري» على نحو مطلق. الاستيراد الثابت الجديد يضيف كوداً إلى مسار العارض المشترك، لكن المحتوى المعروض يظل مشروطاً بالنوع الجديد.

## 3. مطابقة الفهرس المعتمد

| القسم | المنفّذ فعلياً |
|---|---|
| 1 | الكلمات المفتاحية، تسمية المواد الأربع ومكوّناتها، حل التماسك، قراءة الصيغة والتمييز بين الجزيء والوحدة الصيغية |
| 2 | تعريف الكيميائية مرة واحدة، نوعا الروابط، الاستقرار، سعة السوية الأولى وحدود الثمانية |
| 3 | مكوّنات الذرّة، التكافؤ والشحنة، حل أيون الأكسيد بخطوات الحساب، رسم السطح منفصلاً عن التوزيع الكامل |
| 4 | الفلزّات واللافلزّات وجدول المقارنة، الزئبق والغرافيت والهيدروجين، قاعدة الشريك |
| 5 | تعريف الأيونية، نص انتقال NaCl، تفسير الشبكة والوحدة الصيغية، معادلات الانتقال والتحقق، حل اختيار قوة التجاذب |
| 6 | MgO وCaO وNa₂O وMgCl₂: المعطيات والتوزيعات والفقد والاكتساب والنسب والتحقق؛ رسوم المراحل الثلاثة المقرّرة ولويس الأيوني لـ MgCl₂ |
| 7 | إضاءة الأيونية وتعليل الصلابة والخواص الحرارية والتوصيل وحالاته |
| 8 | تعريف المشتركة، حلول أنشطة H₂ وO₂ وN₂ والمقارنة والثمانية، جدول العدّ، رسوم لويس والنماذج، حل اختيار رابطة H₂ |
| 9 | خطوات لويس الأربع، حلول Cl₂ وH₂O وHCl وعدّ الإلكترونات، الرسوم، إضاءة المشتركة والتمييز الجزيئي/الشبكي والاستثناءات |
| 10 | مقارنة بستة محاور، منهج التصنيف، تحليل عناصر قضية البحث وتصنيف المركبات الخمسة مع التعليل والموازنة، قيد AlCl₃، حل فرعي المختلف ومعيار H₂ البديل |
| 11 | خريطة ربط والأخطاء السبعة وتصحيحها، دون تكرار التعريفات |

بطاقة مراجعة مستقلة خارج مقال مادة النسخ، تضم سبعة بنود مهارات واسترجاع.

### التوثيق
- جدول واحد بعنوان «جدول مصادر بنود دفتر الطالب»، يضم **92 صفاً**.
- كل شرح مؤلّف وكل جدول ورسم مسجّل بمسمّى واضح. الصف الواحد قد يوثّق جدولاً كاملاً أو قاعدة متكاملة.
- صف تعريف الرابطة الكيميائية يجمع `p14-bond-definition` و`p16-learn-line-1` ويصرّح بأن العرض مرة واحدة.
- فُصل النص المطبوع عن حلول الأنشطة وحلول الأسئلة وإعادة بناء الرسوم وإضافات المنصة.
- إضافات الدفتر المؤلفة محلياً موثقة بملفها ومسمّى البند، ولا تدّعي أنها مطبوعة في الكتاب.
- `source.verified = false`؛ صور الصفحات الأصلية لم تُعاين مباشرة.

## 4. سجل استبدال assertions المتعارضة

هذه تغييرات عقد دفتر الدرس الثاني فقط، وليست تخفيفاً لقيود الدروس الأخرى. لم تُحذف حالة اختبار من الملف؛ بقيت 22 حالة، بما فيها حالات تبويب «إضافي» دون تعديل.

| الحارس السابق | الحارس البديل وسبب التغيير |
|---|---|
| وجود التصنيف في القسم الافتتاحي | تحقّق العبارة الحرفية في موضعها التعليمي الجديد بالقسم 2 مع إبقاء التحقق من نص المصدر |
| مصادر التعريفات الثلاثة كلها من صندوق تعلّم | بقاء نصوص التعريفات الثلاثة ومطابقتها لنص تعلّم؛ مصدر بيانات التعريف يشير إلى موضعه الأول؛ والجدول يجمع مواضع الورود |
| `transfer.points` يساوي السطرين فقط | تحقّق السطرين المطبوعين حرفياً في القائمة الموسّعة، وجدول الجسيمات الكامل بخمس خانات، واختبارات إضافية للآلية والمعادلات |
| خصائص النوعين في جدول قديم واحد | تحقّق نص إضاءة كل نوع حرفياً في قسمه، مع حراس تعليل الخواص والاستثناءات |
| وجود وسم المنصة المرئي في قسمين وقيمتا الإضافة القديمتان فقط | منع الوسم في المتن، وإلزام جدول المصدر، والتحقق من قاعدة الصيغة ومن محتوى التأسيس والاستثناءات فعلياً |
| قائمة الأقسام الثمانية القديمة بالترتيب | قائمة الأقسام الأحد عشر بالترتيب، مع اختبارات الحلول والجداول والرسوم لا العناوين وحدها |
| قائمة أسماء مركبات البحث فقط | بقاء الصيغ الخمس والأعداد الذرية السبعة، والتحقق من التعليل لكل حالة والحلول الكاملة للمختلف |
| `checklist` غير موجودة | قائمة مراجعة بسبعة بنود، واختبار وجودها خارج مقال النسخ |
| منع `procedure` و`ordered` | إلزام إجراء لويس بأربع خطوات، وحلول الأيونية واللويس في الأقسام المعتمدة |
| منع عبارات أختبر نفسي واختر المختلف | إلزام حلول جميع أسئلة المصدر وفروعها والموازنة والعدّ والتعليل |
| ثلاثة رسوم لويس فقط في كامل الدفتر | بقاء الثلاثة الأصلية وخرائط نقاطها كما هي داخل قسمها؛ إضافة Cl₂ ثابتة، وفحص مستقل لـ H₂O وHCl |
| سبعة ترميزات ذرّية وأربعة توزيعات في الدفتر كله | بقاء السبعة في قضية البحث والأربعة في جدول NaCl؛ العدد الكلي الجديد 11 ترميزاً و35 توزيعاً بسبب الأمثلة الجديدة |
| ثلاثة رسوم فقط في اختبار فتح التبويب | ثمانية مجمّعات رسوم ثابتة وأربعة أمثلة لويس قياسية داخل المقال |
| عنوان تأسيس قديم وأربع نقاط فقط | العنوان التعليمي الجديد، وثلاث فقرات مكتملة وخمسة محاور في جدول المقارنة |
| ظهور ثلاث شرائح ص16 وعدم تفعيل إخفائها | عدم وجود شرائح مصدرية في المتن وتفعيل الإخفاء، وصف واحد يجمع موضعي تعريف الكيميائية |

الاختبارات المضافة تحرس الشحنات وأعداد الإلكترونات والسويات في SVG فعلياً، ونتائج نشاط الجزيئات الثلاثة، وخطوات الأمثلة، ونظافة المتن، وتغطية الجداول والرسوم بالمصدر، واستقلال المحتوى عن فشل حزمة الأدوات، وتغذية راجعة حقيقية للأدوات.

## 5. الاختبارات والأدلة

- البناء النهائي `npm run build`: ناجح (يشمل TypeScript). يبقى تحذير Vite الخاص بالحزم الكبيرة.
- مجموعة اختبارات دفتر الدرس الثاني: **33 اختباراً ناجحاً** في ثلاثة ملفات.
- المجموعة العامة النهائية مع تفعيل Chromium: **59 ملفاً ناجحاً؛ 1269 اختباراً ناجحاً من 1269، دون تجاوزات**. سجلها `tests-with-browser.log`. التشغيل العادي السابق أعطى 1266 ناجحاً و3 اختبارات اختيارية متجاوزة، ثم شُغّلت جميعها في الدورة النهائية.
- أُعيد تشغيل اختبارات الدرس السادس مع تفعيل Chromium: **6/6 ناجحة**، بما فيها الاختبارات الثلاثة الاختيارية عند 1365 و390 و320 بكسل.
- توجد رسالة React `act(...)` تحذيرية في اختبار يتعامل مع رفض التحميل المؤجل؛ ليست فشلاً، ولم يُغيّر إعداد الاختبارات لإخفائها.

### فحص Chromium الفعلي

الأدلة محفوظة في `artifacts/lesson2-notebook/`، وهو مجلد الأدلة المستثنى من Git أصلاً.

- عرض مكتبي 1280px وهاتف 390px: لا تجاوز أفقي على مستوى المستند.
- 11 قسماً، و8 مجمّعات رسوم ثابتة، و92 صف مصدر.
- أربع أدوات: الشحنة، مراحل الأيونية، لويس، المقارنة؛ وخمسة أسئلة تحقق مع تغذية راجعة.
- عُدّلت اختيارات فعلية في الأدوات وفُحصت استجابة لويس وتصحيح الإجابة. باقي حالات الأدوات اختُبرت أيضاً عبر Testing Library.
- الطباعة: الرسوم الثابتة مرئية، أدوات التدريب مخفية، وجدول المصادر موجود مرة واحدة.
- أُوقف طلب `lesson2NotebookWidgets` عمداً في صفحة جديدة: ظهر احتواء الفشل، وبقيت الأقسام الأحد عشر والرسوم الثمانية وحل MgCl₂ الكامل مرئية؛ أُنتج PDF في هذه الحالة.
- عُوينت صور فعلية من PDF، لا مجرد DOM الطباعة. كُشف انقسام رسم H₂O/HCl، وعُدّل فصل الصفحات محلياً، ثم أُعيد التصدير والفحص.
- صُغّرت النواة الرسومية محلياً في رسوم الدفتر إلى 8px لتكون أصغر من المدار الأول في نموذج Ca ذي السويات الأربع، دون تعديل مكوّن BohrAtom المشترك.
- لقطات عرض وطباعة للدروس 1 و3–7؛ لا تظهر فيها أدوات أو رسوم الدرس الثاني. الدرس 7 فُحص بمساره الحالي، لا بدفتر مخترع له.

## 6. الفروق والحدود المتبقية للمراجعة

1. لا نقص مقصود في بنود مادة النسخ الأحد عشر أو حلول الأنشطة وأسئلة الاختبار المقررة، لكن الاعتماد النهائي للمحتوى يبقى للمراجع.
2. لم تُنفّذ بطاقات مصطلحات قابلة للقلب أو زر لتحويل كل مثال إلى عرض يخفي بعض خطواته، خلافاً للتصور التفاعلي الأول الأوسع. نُفّذت بطاقة المراجعة الثابتة المستقلة، وبقيت الحلول كاملة، وأضيف مستكشف مراحل منفصل. يُعرض هذا الفرق صراحةً ولا يُعدّ اكتمالاً لهذه الميزتين.
3. مستكشف الشحنة يعدّ البروتونات والإلكترونات والشحنة؛ لا يرسم توزيعاً مفترضاً لكل شحنة يمكن اختيارها، ولا يدّعي استقرار جميع الخيارات. الرسوم العلمية المعتمدة للتوزيعات موجودة في المتن.
4. المقارن يتيح سبعة أمثلة محددة: NaCl وCaO وNa₂O وMgCl₂ وH₂O وHCl وAlCl₃، وليس كل مادة مذكورة في الدرس.
5. فشل JavaScript الذي اختُبر هو فشل حزمة الأدوات فقط؛ لم يُدّع أن التطبيق يعمل عند تعطيل JavaScript كله.
6. التحقق من صور الكتاب الأصلية مؤجل، و`verified` باقٍ `false`.
7. لا نشر ولا Commit ولا Push ولا PR ولا Merge؛ ينتظر العمل مراجعة المستخدم وموافقته النهائية.
