# Interactive Physics & Chemistry — Grade 8

**منصة تفاعلية تعليمية للفيزياء والكيمياء للصف الثامن**

منصة واحدة، كتاب واحد، مسارَان: **الفيزياء** و**الكيمياء**.

> **حالة المشروع: مرحلة الأساس (Foundation).**
> بُنيت بنية المنصة ونظام العرض العلمي ومسار الدروس ومساحة المعلم بالكامل، لكن
> **لم يُضف أي محتوى دراسي بعد**: لا وحدات، ولا دروس، ولا تجارب، ولا أسئلة.
> السبب: لم تُزوَّد المنصة بصور صفحات الكتاب المدرسي، والكتاب هو المصدر الوحيد للحقيقة.

## التشغيل

```bash
npm ci              # تثبيت التبعيات
npm run dev         # خادم التطوير على http://localhost:5173
npm run build       # بناء الإنتاج + تجهيز dist/404.html
npm run preview     # معاينة مخرجات الإنتاج
npm run typecheck   # فحص الأنواع
npm test            # تشغيل الاختبارات
npm run verify:dist # التحقّق من مخرجات الإنتاج (المسار الأساسي وروابط العمق)
npm run verify      # الأنواع + الاختبارات + البناء + التحقّق
```

## النشر على GitHub Pages

* النشر يتم عبر **GitHub Actions فقط** (`.github/workflows/deploy-pages.yml`).
* لا يوجد نشر من فرع، ولا مزوّد استضافة آخر.
* جميع الأصول تُبنى تحت المسار: `/Interactive-Physics-Chemistry-Grade8/`.
* الموقع يستخدم موجّه متصفّح حقيقي (BrowserRouter) مع `basename` مشتق من `import.meta.env.BASE_URL`،
  ويُنشر `404.html` كنسخة من `index.html` حتى تعمل روابط العمق على صفحات GitHub.
* `npm run verify:dist` يتحقق فعلياً من: المسار الأساسي لكل أصل، وجود `404.html`، وجود الخطوط
  وملفات KaTeX، وخلو الحزمة من `localhost`.

## بنية المشروع

```
src/
  app/              الراوتر، الثيم، التنقل، نقطة الإقلاع
  components/       عناصر مشتركة (Drawer، EmptyState، الأيقونات، InteractiveHost)
  data/             ★ طبقة المحتوى: المخطّط، السجل، المصدر، التقدّم، تحقق الأمانة
  layouts/          هيكل الموقع وإطار الدرس
  lessons/          محرّك الدرس: الأنواع، المخطط، الخطوات، مُصيّرات الخطوات
  pages/            صفحات المسار والمادة والوحدة والدرس
  scientific/       ★ مكوّنات العرض العلمي (انظر docs/SCIENTIFIC_RENDERING.md)
  assessment/       أنواع الأسئلة، التقييم، عرض الأسئلة، الاختبار النهائي
  simulations/      سجل العناصر التفاعلية (تجارب/محاكيات) — فارغ عمداً
  teacher/          بوابة المعلم وأقسامها الثلاثة
  styles/           رموز التصميم، الأساس، المكوّنات، الطبقة العلمية
tests/              اختبارات الأمانة، العرض العلمي، الدرس، التقييم، الوصولية، النشر
scripts/            التحقّق من مخرجات الإنتاج ومهام ما بعد البناء
docs/               توثيق الأمانة المصدرية والعرض العلمي وخطة إضافة الدروس
```

★ = الطبقات التي يجب أن تُقرأ قبل إضافة أي محتوى دراسي.

## قواعد ثابتة

1. **الكتاب هو المصدر الوحيد للحقيقة.** لا يُخترع نص أو رقم أو وحدة أو شكل أو سؤال.
2. **كل ما يضيفه المنصة موسوم** بوسم «إضافة من المنصة / Platform Addition».
3. **كل ما يُنقل من الكتاب موسوم** بإطار «من الكتاب المدرسي» مع رقم الصفحة.
4. **لا يُنشر ما لم يُقرأ.** إذا كانت الصورة غير واضحة، يُطلب توضيح أو يُحفظ المصدر كما هو.
5. **العربية RTL والمحتوى العلمي LTR معزول** بشكل صريح — لا انعكاس للقيم أو الوحدات أو الصيغ.
