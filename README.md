# Interactive Chemistry — Grade 8

**منصة تفاعلية تعليمية للكيمياء للصف الثامن**

منصة تعليمية مستقلة للكيمياء، مبنية على الكتاب المدرسي الرسمي. تعرض المحتوى المصدر كما هو، وتفصل بوضوح بينه وبين شرح المنصة وإضافاتها التفاعلية.

> **حالة المشروع: وحدة كيمياء واحدة وثلاثة دروس موثّقة المصدر.**
> المحتوى المنشور حالياً بحالة `source-verified`: الدرس الأول «الذرّة والعنصر» (الصفحات 3–12)، والدرس الثاني «الروابط الكيميائية» (الصفحات 13–17)، والدرس الثالث «صيغةُ المركّباتِ الكيميائيَّةِ» (الصفحات 18–23).
> لكل درس خطوات وأسئلة كتاب واختبار نهائي. لا تُعرض دروس مستقبلية غير موجودة في السجل؛ الكتاب هو المصدر الوحيد للحقيقة.
> **الوحدة الأولى ما زالت مفتوحة لدروس لاحقة**؛ اختبار الوحدة الحالي «اختبار مرحلي للمحتوى المنشور» ولا يُعلن اكتمال الوحدة حتى إذن صريح.

## محتوى الكيمياء المنشور

جميع الدروس التالية بحالة `source-verified`:

**الكيمياء — الوحدة الأولى «الكيمياء البنيوية»** (الصفحات 3–23، والوحدة مستمرة لدروس لاحقة):

* الدرس الأول — الذرّة والعنصر (الصفحات 3–12) — المسار `atom-and-element`
* الدرس الثاني — الروابط الكيميائية (الصفحات 13–17) — المسار `chemical-bonds`
* الدرس الثالث — صيغةُ المركّباتِ الكيميائيَّةِ (الصفحات 18–23) — المسار `chemical-formulas`

## التشغيل

```bash
npm ci              # تثبيت التبعيات
npm run dev         # خادم التطوير على http://localhost:5173
npm run build       # بناء الإنتاج + تجهيز dist/404.html
npm run preview     # معاينة مخرجات الإنتاج
npm run typecheck   # فحص الأنواع
npm test            # تشغيل الاختبارات
npm run verify:dist # التحقّق من مخرجات الإنتاج (المسار الأساسي وروابط العمق)
npm run verify      # الأنواع + الاختبارات + البناء + التحقّق
```

## النشر على GitHub Pages

* النشر يتم عبر **GitHub Actions فقط** (`.github/workflows/deploy-pages.yml`).
* لا يوجد نشر من فرع، ولا مزوّد استضافة آخر.
* عنوان الموقع: `https://johntaylorjt8870-cell.github.io/Interactive-Chemistry-Grade8/`.
* جميع الأصول تُبنى تحت المسار: `/Interactive-Chemistry-Grade8/`.
* يستخدم الموقع موجّه متصفح حقيقياً (`BrowserRouter`) مع `basename` مشتق من `import.meta.env.BASE_URL`، ويُنشر `404.html` كنسخة من `index.html` حتى تعمل روابط العمق على صفحات GitHub.
* `npm run verify:dist` يتحقق من المسار الأساسي لكل أصل، ووجود `404.html` والخطوط وملفات KaTeX، وخلو الحزمة من روابط `localhost`.

## بنية المشروع

```
src/
  app/              الراوتر، الثيم، تنقل الكيمياء، نقطة الإقلاع
  components/       عناصر واجهة مشتركة
  data/             ★ محتوى الكيمياء، المصدر، التقدّم والتحقق من الأمانة
  layouts/          هيكل الموقع وإطار الدرس
  lessons/          محرّك الدرس: الخطوات، المخطط، ومصيّرات المحتوى
  pages/            الصفحة الرئيسية، مسار الكيمياء، الوحدة والدرس
  scientific/       ★ مكوّنات العرض العلمي وKaTeX
  assessment/       أنواع الأسئلة، التقييم، عرض الأسئلة والاختبار النهائي
  simulations/      سجل وتجارب الكيمياء المنشورة مع تحميل كسول
  teacher/          بوابة المعلم وأقسامها
  styles/           رموز التصميم، الأساس، المكوّنات والطبقة العلمية
tests/              اختبارات المحتوى والعرض العلمي والدرس والتقييم والوصولية والنشر
scripts/            التحقق من مخرجات الإنتاج ومهام ما بعد البناء
docs/               توثيق الأمانة المصدرية والعرض العلمي وإضافة الدروس
```

★ = طبقات المصدر والمحتوى التي يجب قراءتها قبل إضافة محتوى جديد.

## قواعد ثابتة

1. **الكتاب هو المصدر الوحيد للحقيقة.** لا يُخترع نص أو رقم أو وحدة أو شكل أو سؤال.
2. **شرح المنصة موسوم بوضوح** بوسم «شرح المنصة / Platform Explanation»؛ أما المحاكيات والأنشطة فتُعرَّف كإضافات من المنصة.
3. **كل ما يُنقل من الكتاب موسوم** بإطار «من الكتاب المدرسي» مع رقم الصفحة.
4. **لا يُنشر ما لم يُقرأ.** إذا كانت الصورة غير واضحة، يُطلب توضيح أو يُحفظ المصدر كما هو.
5. **العربية RTL والمحتوى العلمي LTR معزول** بشكل صريح؛ فلا تنعكس القيم أو الوحدات أو الصيغ.
