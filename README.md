# Interactive Chemistry — Grade 8

**منصة تفاعلية تعليمية للكيمياء للصف الثامن**

منصة تعليمية مستقلة للكيمياء، مبنية على الكتاب المدرسي الرسمي. تعرض المحتوى المصدر كما هو، وتفصل بوضوح بينه وبين شرح المنصة وإضافاتها التفاعلية.

> **حالة المشروع: وحدة كيمياء واحدة مكتملة المحتوى وسبعة دروس موثّقة المصدر.**
> المحتوى المنشور حالياً بحالة `source-verified`: الدرس الأول «الذرّة والعنصر» (الصفحات 3–12)، والدرس الثاني «الروابط الكيميائية» (الصفحات 13–17)، والدرس الثالث «صيغةُ المركّباتِ الكيميائيَّةِ» (الصفحات 18–23)، والدرس الرابع «التفاعلات الكيميائية» (الصفحات 24–29)، والدرس الخامس «قانونا التفاعل الكيميائي» (الصفحات 30–35)، والدرس السادس «المعادلة الكيميائيّة» (الصفحات 36–39)، والدرس السابع «الحساب الكيميائيّ» (الصفحات 40–49).
> لكل درس خطوات وأسئلة كتاب واختبار نهائي. لا تُعرض دروس مستقبلية غير موجودة في السجل؛ الكتاب هو المصدر الوحيد للحقيقة.
> **اكتمل محتوى الوحدة الأولى بسبعة دروس**؛ الدرس السابع ينتهي عند ص49. بنك اختبار الوحدة في منطقة الاختبارات ما زال مرحلياً ويغطي الدرسين الأول والثاني فقط، وللدروس الثالث إلى السابع اختبارات نهائية مستقلة داخل صفحاتها.

## محتوى الكيمياء المنشور

جميع الدروس التالية بحالة `source-verified`:

**الكيمياء — الوحدة الأولى «الكيمياء البنيوية»** (الصفحات 3–49، مكتملة المحتوى بسبعة دروس):

* الدرس الثاني — الروابط الكيميائية (الصفحات 13–17) — المسار `chemical-bonds`
* الدرس الثالث — صيغةُ المركّباتِ الكيميائيَّةِ (الصفحات 18–23) — المسار `chemical-formulas`
* الدرس الرابع — التفاعلات الكيميائية (الصفحات 24–29) — المسار `chemical-reactions`
* الدرس الخامس — قانونا التفاعل الكيميائي (الصفحات 30–35) — المسار `mass-and-fixed-proportions`
* الدرس السادس — المعادلة الكيميائيّة (الصفحات 36–39) — المسار `chemical-equations`
* الدرس السابع — الحساب الكيميائيّ (الصفحات 40–49) — المسار `chemical-calculations`

الدرس الرابع يحفظ جميع عناصر الصفحات 24–29، ويضم أربعة تفاعلات تعليمية واختبار درس من **20 سؤالاً** وحلولاً مفصلة في تبويب المعلم. اختبار منطقة الاختبارات مستقل من **20 سؤالاً** أخرى وفق بنية المنصة. لم ينشأ اختبار ختامي للوحدة؛ البنك المرحلي السابق بقي دون توسعة. انظر [تقرير المصدر والتغطية](docs/source-reports/lesson4-chemical-reactions-intake.md).

الدرس الثاني بُني ليكون مكتفياً بذاته تماماً لطالب الصف الثامن المتعلّم بمفرده؛ يضمّ البناء الحالي **38 خطوة** تبدأ من التأسيس الذري والأيوني والفلزّي/اللافلزّي وتنتهي بالاختبار الشامل، وسجل مصدر يغطي كل عنصر مطبوع في الصفحات 13–17 (**45 مدخلاً**: 42 `implemented`، 2 `reconstructed`، 1 `decorative`، ولا عنصر `unresolved`)، **9 حلول أنشطة** و**7 أسئلة كتابية** بنصّها المطبوع، **34 سؤال تدريب** متدرّجاً بتعليل الخيار الصحيح واستبعاد البدائل الخاطئة، واختبار نهائي من **17 سؤالاً (20 جزءاً محتسباً)**. يحوي الدرس أمثلة محلولة مبرَّرة الخطوات (MgO/CaO بنسبة 1:1، وNa₂O بنسبة 2:1، وH₂O/HCl بتمثيل لويس)، و**8 رسوم تعليمية** (منها ميزان شحنة الذرّة والأيون وخريطة إلكترونات السطح وخريطة تمثيل لويس وتمثيل لويس لـ H₂O وHCl وسلسلة السطح←الصيغة وآليتا CaO وMgCl₂) و**6 تفاعلات** (منها مختبر استنتاج سلوك الذرّات مع تغيّر الشريك، وعدّ السطح، وخطوات تكوين الرابطة، وكشف الخطأ بست عبارات)، ودليل معلّم موسَّع. للتحقق في متصفّح حقيقي: `npm run verify:lesson2`. التقرير الكامل: [LESSON2_FINAL_REPORT.md](LESSON2_FINAL_REPORT.md).

الدرس الخامس أُعيد بناؤه بالكامل فوق بنية المنصة نفسها اعتماداً على صور الصفحات 30–35 المرفقة: **28 خطوة**، سجل مصدر برمجي (`lesson5SourceLedger.ts`) يغطي كل عنصر مطبوع (42 مدخلاً: 38 `implemented`، 3 `reconstructed`، 1 `decorative` مبررة، ولا عنصر `unresolved`)، **19 وحدة كتابية** (11 نشاطاً وتجربة و8 وحدات «أختبر نفسي» بفروعها) بنصّها المطبوع وترتيبها — بما في ذلك حفظ الخطأ المطبعي «الكبريت» في سؤال ص33 مع تنبيه صريح، وقيمة 2.66 المطبوعة في ص35 مفصولة عن الحساب الدقيق 2.666… — و**20 سؤال تدريب** متدرّجاً من المنصة، واختبار نهائي خاص بالدرس من **20 سؤالاً**، وثلاثة مختبرات وثلاثة أشكال مصدرية مُعادة البناء (ميزان ص30، ميزانا ص31، تجارب ص32)، ودليل معلّم شامل. لم يُنشأ له بنك مستقل أو اختبار وحدة إضافي. تقارير المصدر والتغطية: [سجل المصدر](docs/source-reports/lesson5-source-audit.json) و[تقرير إعادة البناء](docs/source-reports/lesson5-rebuild-and-coverage.md). للتحقق في متصفّح حقيقي: `npm run verify:lesson5`.

الدرس السادس «المعادلة الكيميائيّة» بُني ذاتيّ الاكتفاء اعتماداً على صور الصفحات 36–39 المرفقة: **35 خطوة** تعليمية متدرّجة، سجل مصدر برمجي (`lesson6SourceLedger.ts`) يغطي كل عنصر مطبوع (**34 مدخلاً**: 32 `implemented`، 1 `reconstructed`، 1 `decorative` مبررة، ولا عنصر `unresolved`)، **20 وحدة كتابية** (13 نشاطاً وتساؤلاً وتجربة في سياق الدرس و7 وحدات «أختبر نفسي» بسؤاليها)، **28 سؤال تحقق وتدريب متدرّج** (30 جزءاً محتسباً)، واختبار نهائي شامل من **20 سؤالاً**، مع **4 أشكال تعليمية ومصدرية** و**4 مختبرات وأنشطة تفاعلية** ودليل معلّم مفصّل. تقارير المصدر والتغطية: [سجل المصدر](docs/source-reports/lesson6-source-audit.json) و[تقرير البناء والتغطية](docs/source-reports/lesson6-rebuild-and-coverage.md) و[LESSON6_FINAL_REPORT.md](LESSON6_FINAL_REPORT.md). للتحقق في متصفّح حقيقي: `npm run verify:lesson6`.

الدرس السابع «الحساب الكيميائيّ» يغطي الصفحات 40–49: **33 خطوة**، سجل مصدر من **194 بنداً** (193 واضحاً وبند واحد مؤجل لتسمية الميزان البيضاء في ص41 مع حفظ الرسم الأصلي)، **41 وحدة سؤال كتابي** بحلول مرجعية، **12 سؤال تدريب** من المنصة، واختبار نهائي جديد من **20 سؤالاً**، ومختبران حسابيان (الكتلة المولية والحجم المولي)، ودليل معلم. تُعلن نسبة **21% حجماً** للأكسجين في الهواء بوصفها افتراض حل من المنصة لا معطى كتابياً. التقرير: [اعتماد المصدر وتنفيذ الدرس السابع](docs/source-reports/lesson7-approval-and-implementation.md). للتحقق في متصفح حقيقي: `npm run verify:lesson7`.

## التشغيل

```bash
npm ci              # تثبيت التبعيات
npm run dev         # خادم التطوير على http://localhost:5173
npm run build       # بناء الإنتاج + تجهيز dist/404.html
npm run preview     # معاينة مخرجات الإنتاج
npm run typecheck   # فحص الأنواع
npm test            # تشغيل الاختبارات
npm run verify:dist # التحقّق من مخرجات الإنتاج (المسار الأساسي وروابط العمق)
npm run verify      # الأنواع + البناء + التحقّق + الاختبارات (بترتيب CI نفسه)
npm run verify:lesson1 # فحص Chromium متجاوب للدرس الأول (يلزم تثبيت أدوات المتصفح الاختيارية)
npm run verify:lesson2 # فحص Chromium متجاوب للدرس الثاني (38 خطوة × ثلاثة عروض + الرسوم الثمانية والمختبرات الستة + axe)
npm run verify:lesson3 # فحص Chromium متجاوب للدرس الثالث (يلزم تثبيت أدوات المتصفح الاختيارية)
npm run verify:lesson4 # فحص Chromium للإنتاج للدرس الرابع (يلزم تثبيت أدوات المتصفح الاختيارية)
npm run verify:lesson5 # فحص Chromium متجاوب للدرس الخامس (يلزم تثبيت أدوات المتصفح الاختيارية)
npm run verify:lesson6 # فحص Chromium متجاوب للدرس السادس (يلزم تثبيت أدوات المتصفح الاختيارية)
npm run verify:lesson7 # فحص Chromium متجاوب للدرس السابع (33 خطوة × ثلاثة عروض + القصّات الأربع والمختبران + axe)
npm run verify:badges  # فحص Chromium لهندسة الشارات والرموز العلمية المشتركة (يلزم تثبيت أدوات المتصفح الاختيارية)
```

أدوات المتصفّح الاختيارية لفحوص Chromium ليست من تبعيات المشروع؛ ثبّتها عند الحاجة بنفس الإصدارات المثبّتة في CI: `npm install --no-save puppeteer-core@25.16.0 @sparticuz/chromium@153.0.0` (أو عيّن `CHROMIUM_PATH` لمتصفح موجود). وتشغّل CI فحصي `verify:badges` و`verify:lesson6` على كل طلب سحب؛ أما فحوص الدروس 1–5 فتبقى أوامر محلية لطول زمن تشغيلها.

## النشر على GitHub Pages

* النشر يتم عبر **GitHub Actions فقط** (`.github/workflows/deploy-pages.yml`).
* لا يوجد نشر من فرع، ولا مزوّد استضافة آخر.
* عنوان الموقع: `https://johntaylorjt8870-cell.github.io/Interactive-Chemistry-Grade8/`.
* جميع الأصول تُبنى تحت المسار: `/Interactive-Chemistry-Grade8/`.
* يستخدم الموقع موجّه متصفح حقيقياً (`BrowserRouter`) مع `basename` مشتق من `import.meta.env.BASE_URL`، ويُنشر `404.html` كنسخة من `index.html` حتى تعمل روابط العمق على صفحات GitHub.
* `npm run verify:dist` يتحقق من المسار الأساسي لكل أصل، ووجود `404.html` والخطوط وملفات KaTeX، وخلو الحزمة من روابط `localhost`.

## قواعد ثابتة

1. **الكتاب هو المصدر الوحيد للحقيقة.** لا يُخترع نص أو رقم أو وحدة أو شكل أو سؤال.
2. **شرح المنصة موسوم بوضوح** بوسم «شرح المنصة / Platform Explanation»؛ أما المحاكيات والأنشطة فتُعرَّف كإضافات من المنصة.
3. **كل ما يُنقل من الكتاب موسوم** بإطار «من الكتاب المدرسي» مع رقم الصفحة.
4. **لا يُنشر ما لم يُقرأ.** إذا تعذرت مراجعة تفصيل من المصدر، يوثّق العائق بوضوح ولا يُخمّن.
5. **العربية RTL والمحتوى العلمي LTR معزول** بشكل صريح؛ فلا تنعكس القيم أو الوحدات أو الصيغ.
